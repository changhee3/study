# 머신러닝 알고리즘

머신러닝 알고리즘은 지도 학습과 비지도 학습으로 나뉜다.

## 지도 학습

**필요 요건 : 훈련 데이터, 정답**

데이터 : **입력(input)**
정답 : **타깃(target)**

데이터와 정답을 합쳐 **훈련 데이터**라고 부른다.

데이터를 구분하는 기준을 **특성**이라고 한다.
예) 길이, 무게 등등

### 문제를 푸는 모델에 대해서

평가에 사용하는 데이터를 **테스트 세트**라고 한다.
훈련에 사용하는 데이터를 **훈련 세트**라고 한다.

2차원 배열로 데이터가 있을 때 하나의 값을 **샘플**이라고 부른다.
그래서 모델을 학습 시킬 때 훈련 세트의 데이터와 테스트 세트의 데이터를 분류하여 학습시켰다.

## 샘플링 편향

**훈련 세트와 테스트 세트에 샘플이 골고루 섞여 있지 않는 현상**

## 넘파이(numpy)

파이썬의 대표적인 **고차원 배열 표현 라이브러리**

## 넘파이 제공 속성들

### 슬라이싱 연산자

콜론( : )을 가운데에 두고 원하는 원소를 고르는 방법.
예) print(fish_data[0:5])라면 인덱스 번호 0번부터 5번의 직전 번호인 4번까지 총 5개의 원소가 출력된다.

### shape

넘파이 라이브러리의 속성
배열의 차원에서 각 축의 크기를 튜플(수정 불가능한 소괄호 배열)로 출력하는 속성

### random.seed(x)

난수 생성기의 초기값을 x로 고정한 후 다음번에 난수를 생성할 때도 같은 수로 난수가 생성된다

### arange

원소가 순서대로 정리된 배열을 만든다
예) [0, 9, 4, 7] → [0, 4, 7, 9]

### shuffle

배열에 있는 인덱스 순서를 무작위로 섞는다
