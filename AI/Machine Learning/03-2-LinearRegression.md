# 선형 회귀

특성이 하나인 경우에 직선을 학습하는 알고리즘
예) print(knr.predict([[100]]))같은 코드에서는 오로지 길이 데이터로만 무게를 예측해낼 수 있다.

클래스는 **LinearRegression**을 사용한다.
이 클래스는 데이터셋을 가장 잘 표현할 수 있는 선을 찾기 위해 직선의 방정식을 그린다.
y = wx + b의 직선의 방정식을 만들고, 여기는 가중치(weight)를 나타내는 coef_ 속성이 있다.
또한 b는 y절편이며 intercept_라는 속성을 사용한다.

### coef_ 속성

데이터들을 가장 잘 표현한 직선의 기울기(가중치)를 저장하는 속성.

### intercept_ 속성

데이터들을 가장 잘 표현한 직선의 y절편을 저장하는 속성.

위의 두 속성 coef_와 intercept_ 속성은 fit()함수로 최소제곱법을 이용하여 최적의 직선의 식을 구한다. 
그리고 기울기는 coef_에, y절편은 intercept_에 저장된다.

## 다항 회귀

선형 회귀중 **2차 방정식 이상의 차수를 이용하여 선을 그릴 경우 다항회귀라고 한다.**

### 파라미터

함수의 식 y = ax² + bx + c 등이 있을 때 
미지수를 제외한 상수와 미지수의 계수를 모두 **파라미터**라고 부른다.
쉽게 말해 모델이 변환시킬 수 있는 모든 값을 파라미터라고 한다.
만약 위와같은 식이 있다면 저 식에 대한 모델 파라미터는 3개이다. (a, b, c) 

### MAE [ 평균 절대 오차]

Σ|실제값 − 예측값| / n으로 나타낼 수 있으며
이 식의 의미는 **"예측값이 실제값과 평균적으로 얼마나 차이 나는가”**이다.
간단히 **모델의 예측과 정답의 오차를 평균으로 계산한 것**이 MAE이다.

### 최소제곱법(LSM)

선형 회귀에서 데이터들을 가장 잘 표현할 수 있는 직선을 찾기 위해 사용하는 계산법이다.

### np.arange()

넘파이 함수이며 괄호 안에 a, b의 값을 넣으면 a~ b-1까지의 연속된 정수를 생성해준다.

## [(길이)², (길이)] 배열을 사용하는 이유

만약 (길이)데이터만 갖고 선형 회귀를 그린다면 직선으로밖에 못그려 데이터들을 더 자세하게 설명할 수 있는 선을 그리기 힘듬.
그래서 2차 이상의 방정식을 사용하면 곡선형으로 데이터들을 표현할 수 있기 때문에 제곱을 사용한다.

### .score 메서드

knn 모델과는 다르게 예측값이 결정 계수(R²)로 나타내서
점수가 **평균값으로 찍은 선보다 예측으로 찍는 것이 얼마나 더 나은가로 나타난**다.
