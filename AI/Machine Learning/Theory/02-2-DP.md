## 데이터 전처리

샘플 데이터들간의 거리, 특성값을 일정한 기준으로 맞추는 작업을 **데이터 전처리** 라고 한다.

### 대표적인 전처리 방법

#### 표준점수

각 특성에 해당하는 값 하나가 표준편차의 몇 배만큼 떨어져 있는지를 나타내는 방법.
**표준점수 표현법 : (데이터값 - 평균) / 표준편차**

※ 분산 : Σ(각 데이터에서 평균과의 편차)² /n
     ㄴ> Σ는 시그마, 모든 값들을 더한다는 뜻이다.

## 표준 점수를 구하는 식의 원리

표준점수를 구하는 식은 각 데이터들의 편차를 구한 후 각 데이터를 표준편차로 나눈다.
**데이터 - 평균을 할 때 평균으로부터 떨어져 있는 데이터의 값은 모든 데이터들끼리 비례한다.**
이 때 표준편차로 나눈다면 표준편차의 원리에 따라서 **퍼짐의 단위가 1로 재조정 된다.**
편차 = x(각 데이터 값) - mean(평균)
분산 = {(편차1)² + (편차2)² + (편차3)² + … + (편차n)²} / n(데이터의 갯수)
**표준점수 = {(각 데이터 값) - mean(평균)} / std(표준 편차)**

### mean 함수

데이터값의 평균을 구하는 함수
예) mean = np.mean(train_input, axis=0)
      ㄴ> mean 변수에 np.mean 함수를 사용해서 train_input 값을 넣고 axis 옵션을 사용해서 배열의 순서별로 값을 더한다음 값의 개수만큼 나눈다. 
이 방법으로 데이터들의 평균값을 구한다.

### std 함수

데이터값의 표준편차를 구하는 함수

예) std = np.std(train_input, axis=0)
      ㄴ> std 변수에 np.std 함수를 사용해서 train_input값을 넣고 axis 옵션을 사용해서 배열의 분산을 구한후 제곱근을 씌워 표준편차를 구한다.

### 표준점수

각 특성값이 **평균에서 표준편차의 몇 배만큼 떨어져 있는지**를 나타내는 것.

예) train_scaled = (train_input - mean) / std
train_scaled라는 변수에 train_input 데이터를 mean(평균값)으로 뺀 값을 std(표준편차)로 나눈 값을 대입한다.
