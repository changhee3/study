## 다중 회귀

여러개의 특성을 사용하여 나타낸 선형 회귀
만약에 **2개의 특성을 사용하면 선형 회귀 모델은 평면을 학습한다.**

### 특성 공학

기존의 특성을 사용하여 새로운 특성을 뽑아내는 작업을 특성공학 이라고 부른다.
예) 넓이 * 높이 = (부피)로 두 개의 특성을 연산하여 하나의 특성을 만들어 내는 것이다.

### CSV file

쉼표로 값을 구분하는 순수 텍스트 파일 형식이다.
예) length,height,width,weight
      8.4,2.11,1.41,5.9
      13.7,3.53,2.0,32.0
      15.0,3.82,2.43,40.0

### 변환기

사이킷런에서 전처리(데이터를 가공)를 위해 제공하는 클래스이다.
예) 모델 클래스에는 fit(), score(), predict()가 있을 때 
변환기 클래스에는 fit(), transform() 메서드를 차례대로 호출해야 사용할 수 있다.

### transform 메서드

데이터의 형태, 값, 구조를 **변환하는 작업**을 담당한다.
예) print(poly.transform([[2, 3]]))
      ㄴ> [2. 3. 4. 6. 9.]가 출력된다.
**include_bias :** 결과에 상수항을 추가할 것인지 판단하는 옵션.
예) include_bias=False → 결과값에서 1을 삭제한다.
.fit([[2, 3]])을 해도 2,3의 특성 조합법을 학습하고 print(변수명.transform([[120, 260]]))등의 큰 숫자를 넣어도 정상적으로 조합을 만들어 준다.

### PolynomialFeatures 클래스

전처리를 위한 클래스이며 기존에 있던 변수를 이용해 새로운 특성을 만들어 내는 클래스.
예) poly = PolynomialFeatures(degree=5, include_bias=False)
poly.fit(train_input)
train_poly = poly.transform(train_input)
test_poly = poly.transform(test_input)
print(train_poly.shape) 일 때
      poly를 train_poly의 특성은 55개가 된다.

## 규제

**가중치(계수)가 뛰어버리는 현상을 제한**하는것
모델이 훈련 세트에 대해서 과대적합이 나타나는 현상을 방지하기 위해 규제를 사용한다.
벌점항이라는게 있는데 오차 + 가중치²값으로 값의 벌점을 맥인다.

### 릿지(ridge)

(계수)²을 기준으로 규제를 적용한다.

### 라쏘(lasso)

|계수|를 기준으로 규제를 적용한다.
