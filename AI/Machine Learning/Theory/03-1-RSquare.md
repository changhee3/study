# 결정 계수

상태: 완료

## 회귀

샘플을 몇 개의 클래스 중 하나로 분류하는 문제
**두 변수 사이의 상관관계를 분석하는 방법**

※ 클래스중 **하나로 분류하는 것이 아닌, 임의의 숫자를 예측하는 문제**이다.

### .reshape 메서드

원소는 그대로 유지한 채로 배열의 차원구조를 바꿔주는 메서드
※ 03-1 코드에서는 reshape를 2차원 배열로 변환하는 용도로 사용되었다.
예) [1, 2, 3]같은 1차원 배열의 크기 : (3,)
      특성이 2개이기 때문에 값을 2개로 나타내기 위해 2차원 배열로 바꾸면 
[[1],
[2],
[3]]
처럼 바뀐다. 이 배열의 크기를 나타내면 (3,1)이 된다.

### split 메서드

전체 샘플 데이터중 25%는 test용, 75%는 train용도로 데이터를 나누고, 03-1 단원의 목적은 length 값을 갖고 train_input과 target으로 훈련을 한 다음 test_target 값을 모델이 예측하는 과정을 코드로 작성하기 때문에 

### 결정 계수(R²)

R² = 1 - {(타깃 - 예측)²의 합 / (타깃 - 평균)²의 합}
이 숫자의 의미는 **"평균으로만 예측했을 때 생기는 전체 오차(분산)를, 모델이 몇 %나 줄였는가”**이다.

### 과대적합

모델이 훈련 세트에서는 최고였지만 테스트 세트에선 최악의 점수를 내뱉는 현상
예) 훈련 세트 : 99점, 테스트 세트 : 36점

### 과소적합

훈련 세트보다 테스트 세트의 점수가 높거나 모든 세트의 점수가 낮은 현상
예) 훈련 세트 : 60점, 테스트 세트 : 95점
                                 or
      훈련 세트 : 30점, 테스트 세트 : 32점

※ 회귀 모델의 결정 계수를 증가시키는 방법중 하나는 이웃 개수를 조정하는 방법도 있다.
